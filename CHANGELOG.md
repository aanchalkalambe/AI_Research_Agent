## [1.0.0] - 2026-07-25

### 🎉 Initial Release

The first stable release of **AI Research Agent**, an AI-powered workflow built with **n8n**, **OpenAI**, and **Tavily** to automate AI news research and newsletter generation.

### Added

#### Workflow Automation

- Automated daily execution using n8n Schedule Trigger
- End-to-end workflow orchestration
- Modular workflow architecture

#### AI News Collection

- Integrated Tavily Search API
- Automated retrieval of the latest AI news
- Support for multiple trusted AI news sources

#### Data Processing

- JavaScript-based preprocessing
- Structured JSON formatting
- Duplicate article removal
- Data cleaning and validation

#### AI-Powered Summarization

- Integrated OpenAI GPT
- Importance-based article ranking
- Concise news summaries
- AI category classification
- "Why It Matters" impact generation

#### Newsletter Generation

- Dynamic HTML newsletter creation
- Responsive email layout
- Professional formatting
- Source attribution with article links

#### Email Automation

- Gmail integration
- Automated newsletter delivery
- Scheduled email distribution

#### Documentation

- Comprehensive README
- Architecture documentation
- Workflow explanation
- Setup guide
- Prompt documentation
- Sample outputs
- Example newsletter

#### Repository

- MIT License
- Roadmap
- Changelog
- Organized project structure
